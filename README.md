# 🤖 InspireBot-Java

> 🧠 Your daily dose of inspiration — written in Java!

## 💫 Overview
**InspireBot** is a simple Java console application that spreads positivity and motivation!  
It asks for your current mood or goal and replies with an inspiring quote to cheer you up or keep you going.  

This project shows how creativity, emotion, and technology can blend beautifully — because even code can inspire lives. 🌈  

---

## 🧠 Features
- Asks for your mood or goal  
- Responds with motivational quotes  
- Randomized positive messages for variety  
- Beginner-friendly Java logic with loops and arrays  

---

## 🛠️ Tools Used
- Java (JDK 8 or later)
- Any IDE (VS Code, IntelliJ, or Eclipse)

---

## ▶️ How to Run
1. Save the file as `InspireBot.java`
2. Compile:
   ```bash
   javac InspireBot.java
